# Paradise Nursery - e-plantShopping Application

Paradise Nursery is an e-commerce React web application designed for plant enthusiasts to explore, select, and purchase a variety of house plants.

## Features
- **Landing Page:** Welcomes users with project information and a seamless call-to-action.
- **Product Listing:** Browse multiple categories of indoor plants with pricing and description.
- **Shopping Cart:** Add, remove, and adjust item quantities dynamically using Redux Toolkit state management.
- **About Us Section:** Learn more about Paradise Nursery's mission and background.
